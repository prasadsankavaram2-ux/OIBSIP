# GitHub upload instructions

1. Create a public GitHub repository named exactly `OIBSIP` (if you have not already created it).
2. Download and extract this project folder.
3. Place the folder inside your local `OIBSIP` repository and ensure its name is exactly:
   `DataScience-L1-IrisClassification`
4. Open a terminal in the parent `OIBSIP` directory and run:

```bash
git add DataScience-L1-IrisClassification
git commit -m "Add Iris flower classification data science project"
git push origin main
```

5. Open the public repository on GitHub and verify that the notebook, report, README, source code, and outputs are visible.
6. Use the repository URL in the OIBSIP task submission form.

If your default branch is named `master`, push to `master` instead of `main`.
